yoxi 點燈城是放在 yoxi App 裡的新分頁。整個體驗是一個每日循環：早上打開，車燈小精靈送上今天的情境任務和幸運數字；大約一半的任務不用搭車也能完成；走在路上遇見 yoxi 車，可以拍下來收集小精靈、和朋友比幸運數字；遇到下雨、晚歸或活動散場，AI 會推薦叫車，空車時段還有乘車金；搭車時車燈會點亮整條路線，隔天又有新的理由打開。
